## Overview

This project implements a **CNN-based perceptual image hashing scheme**.
Perceptual hashes are compact binary fingerprints of an image that stay
(almost) unchanged under common content-preserving distortions — compression,
noise, filtering, rotation, brightness/colour adjustment — while still
changing when the actual visual content changes. That makes them useful for
image authentication, copy detection, and near-duplicate retrieval.

The pipeline (see the thesis, Chapter 3, for the full derivation):

```
   image → resize/preprocess → VGG16 conv layers → global average pooling
         → 512-d feature vector → mean-thresholded binarisation → 512-bit hash
```

Similarity between two images is then measured with the **Hamming distance**
between their hash codes, and the scheme is evaluated by sweeping a decision
threshold ε and plotting the resulting **ROC curve** (TPR vs. FPR).

## Repository structure

```
perceptual-image-hashing-cnn/
├── data/
│   ├── raw_images/          # put your source images here (50 used in the thesis)
│   └── transformed/         # auto-generated by generate_dataset.py
├── docs/
│   └── Perceptual_Image_Hashing_Thesis.pdf   # full thesis report
├── results/                 # auto-generated: CSVs, ROC curve PNG
├── src/
│   ├── feature_extractor.py # VGG16 / VGG19 feature extraction (Sec. 3.2)
│   ├── hash_utils.py        # binarisation + Hamming distance (Sec. 3.3)
│   ├── transformations.py   # the 10 content-preserving attacks (Table 3.1)
│   ├── generate_dataset.py  # builds transformed images + ground-truth pairs
│   ├── compute_hashes.py    # Algorithm 1: hash generation
│   └── evaluate.py          # Algorithm 2: threshold sweep, ROC, AUC, EER
├── main.py                  # runs the full pipeline end to end
├── requirements.txt
└── README.md
```

## Setup

```bash
git clone https://github.com/<your-username>/perceptual-image-hashing-cnn.git
cd perceptual-image-hashing-cnn

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

**Add your images:** place the image files you want to evaluate (JPEG/PNG)
into `data/raw_images/`. The thesis used 50 images spanning animals, plants,
and everyday scenes.

## Running the pipeline

Run everything in one go:

```bash
python main.py
```

Or run each stage individually:

```bash
# 1. Apply the 10 transformations x 10 parameter settings, build ground truth
python src/generate_dataset.py

# 2. Extract VGG16 features and binarise them into 512-bit hashes
python src/compute_hashes.py

# 3. Sweep the decision threshold, plot the ROC curve, report AUC / EER
python src/evaluate.py
```

Outputs land in `results/`:

| File | Description |
|---|---|
| `transform_log.csv` | every transformed image generated, with its parameter |
| `ground_truth_pairs.csv` | `(image_a, image_b, label)` pairs, label 1 = similar, 0 = dissimilar |
| `hash_database.csv` | 512-bit hash code for every original and transformed image |
| `threshold_metrics.csv` | TP/FP/FN/TN, TPR, FPR, Precision, F1 at each swept threshold |
| `roc_curve.png` | the ROC curve (reproduces Figure 4.1 in the thesis) |

## Notes on reproducing thesis figures

- `results/roc_curve.png` reproduces the shape of Figure 4.1 (VGG16 ROC
  curve), though exact TPR/FPR values will vary slightly depending on the
  specific images placed in `data/raw_images/`.
- The 10 transformation categories and their parameter grids in
  `src/transformations.py` follow Table 3.1 exactly.
- `results/ground_truth_pairs.csv` follows the pairing scheme of Table 3.2
  (each image's 100 transformed variants form its similar pairs; variants of
  every other image form its dissimilar pairs).

## Future work

As discussed in Chapter 5 of the thesis, a natural extension is to fine-tune
the VGG16 backbone end-to-end with a contrastive/triplet loss plus a
quantisation penalty (Equations 3.14–3.16), rather than relying on features
transferred from ImageNet classification. This is **not** implemented here —
the current code uses a frozen, pretrained backbone, matching what was
actually evaluated in the thesis.
