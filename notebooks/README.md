# Notebooks

Optional space for exploratory work — e.g. visualising a few hash codes,
plotting the Hamming-distance distribution for similar vs. dissimilar pairs,
or trying out a different CNN backbone (VGG19) interactively.

Not required to reproduce the thesis results: the scripts in `src/` (run via
`main.py`) are sufficient for that. Add your own `.ipynb` files here as
needed.
